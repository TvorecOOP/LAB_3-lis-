# ToDo Менеджер (Вариант 15)

**Лабораторная работа №3: Работа с графическим интерфейсом на Python**

## Описание
MVP-проект на языке Python с графическим интерфейсом (GUI) на базе PySide6. 
Приложение представляет собой систему учета задач (ToDo). Оно позволяет добавлять, удалять и изменять статус задач, а также строить график активности по дням.

## Инструкции по запуску
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите программу: `python main.py`

## Краткая справка
- **Добавление:** Введите название и описание, нажмите «Добавить задачу».
- **Статус:** Выделите задачу в таблице, выберите статус и нажмите «Обновить статус».
- **Удаление:** Выделите задачу и нажмите «Удалить выбранную».
- **График:** Справа автоматически отображается активность действий по дням.

## Тестирование
Для запуска тестов используйте: `pytest tests/ -v`
